# bm_main

Path: \modules\custom\bm_main

## Overview
  The **Blue Marloc Main** module provides a central entry point for
  all Blue Marloc functionality. It creates the admin menu structure and groups
  related tools under `Administration`, `Entity`, `Data production`, and `Management`.

## Features

* Top-level `Blue Marloc` menu under `Administration`
* `Blue Marloc` icon in menu
* Submenu's for `Administration`, `Entity`, `Data production`, and `Management`
* Landing pages that auto-list child tools

## Usage

Use in your menu the parents:
* `bm_main.bluemarloc_admin`
* `bm_main.bluemarloc_entity`
* `bm_main.bluemarloc_data`
* `bm_main.bluemarloc_manager`
